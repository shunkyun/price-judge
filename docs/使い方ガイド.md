# 価格チェッカー　使い方ガイド

「この値段、高いの？安いの？」を、信頼できる通販サイトの実際の価格と比べて判定するツールです。

## 使い方（3ステップ）
1. **調べたい物を入れる**
   - 商品名を入力（例：ナイキ エアフォース1）。入力の途中で候補が出るので、選ぶだけでもOK
   - または、商品ページのURLを貼り付け
   - 名前が分からない物は 📷 ボタンで写真を選ぶ → AIが候補を出すので、正しいものを選ぶ
     （写真は商品特定のため外部のAIサービスに送信されます。人物や個人情報が写った写真は使わないでください）
2. **「調べる」を押す**
3. **結果を見る**
   - 一番上に判定：**安い / 適正 / 高い**（検討中の総支払額を入力すると判定されます）
   - 「適正価格帯」＝ 集めた価格の真ん中50%の範囲
   - グラフ：価格の推移と、いまの価格のばらつき
   - 表：どのお店でいくらだったか（リンク・取得日時つき）

## 判定の考え方
- 比べる金額は **総支払額（税込価格＋送料＋手数料）** です。送料が分からないお店のデータは使いません
- 「実質価格（参考）」ボタンで、ポイント分を差し引いた分布も見られます（判定は常に総支払額）
- 型番や世代（例：第2世代と第1世代）、上位モデル（Pro・Max など）が違う商品は自動的に除外します
- 集まったデータが少ない（10件未満、2サイト未満、3店舗未満）ときは、無理に判定せず **「データ不足のため判定不可」** と表示し、価格帯も表示しません
- 極端に安い値段は「安すぎ（要注意）」と表示します。偽物や詐欺の可能性があります

## 安心して使うために
- 表示される価格はすべて、今回お店のサイトから取得したものです。AIが価格や説明を作ることはありません
- 対象のお店は信頼できるサイトに限っています（画面下の「対応サイト一覧」で、お店ごとに「自動で検索できるか」「URLを貼って読めるか」を確認できます）
- 家電量販店・セレクトショップ・スポーツ店などの専門店は、そのお店の楽天市場店・Yahoo!店の価格を「ケーズデンキ（楽天市場店）」のように表示します（楽天・Yahoo!のAPIキーを設定したときだけ）
- 画面上部に黄色い帯で「デモモード」と出ているときは、**架空のサンプルデータ** です
- 入力した商品名が他の人に見られたり、入力候補に出たりすることはありません
- 入力欄に氏名・電話番号・住所などは入れないでください
- 最終的な購入判断はご自身で行ってください

# 管理者向け：自分のPCで動かす・公開する

> ### ⚠ いちばん大事なこと（APIキーを漏らさない）
> - **APIキーは「自分のPCの中の `.env`」か「Render の設定画面」にだけ書きます。** それ以外（GitHub、メール、チャット、共有フォルダ）には絶対に置かないでください。
> - **公開用に GitHub へアップロードするフォルダには `.env` を入れません。** GitHub の画面からドラッグ＆ドロップでアップロードすると、`.gitignore` の設定は**無視され**、`.env` もそのまま公開されます。
> - アップロードには、**`scripts/package.sh`（Windows は `scripts\package.bat`）で作った zip を展開したフォルダ**を使ってください。この zip には `.env` やデータベースが入らないようになっており、もし元のフォルダに `.env` があれば警告が出ます。
> - リポジトリは **Private（非公開）** で作成してください。
> - 万一キーを公開してしまったら、すぐに各サイトの管理画面でキーを**削除（無効化）して再発行**し、Render の設定を新しいキーに置き換えてください（楽天：アプリ管理画面 →「削除」して再登録／Yahoo!：アプリケーションの管理 →「削除」して再登録／AIサービス：APIキー画面で Revoke）。

## 自分のPCで試す（デモ）
1. Python（3.12以上）を https://www.python.org/ からインストール（Windowsは「Add python.exe to PATH」にチェック）
2. 配布された `price-judge.zip` を展開
3. Windows：`scripts\start.bat` をダブルクリック ／ Mac：ターミナルで `./scripts/start.sh`
   - 初回だけ必要な部品をインターネットから取り込みます（数分）。2回目以降は取り込みを省略します
   - 庁内ネットワーク（プロキシ・閉域網）で取り込みに失敗する場合は、情報システム担当にご相談ください（`pip` が使える回線が必要です）
4. 準備ができると自動でブラウザが開きます（http://localhost:8000）。APIキーが無い間は**デモモード**（架空のサンプルデータ）です

## 自分のPCで本物の価格を使う（APIキーの取得）
1. **楽天**：https://webservice.rakuten.co.jp/ に楽天会員でログイン → 「アプリID発行」→ アプリ名・アプリURL（公開するURL）を登録 → 表示される「アプリケーションID」と「アクセスキー（pk_で始まる）」を控える
2. **Yahoo!**：https://e.developer.yahoo.co.jp/register にYahoo! JAPAN IDでログイン → 「アプリケーションの登録」→ 表示される「Client ID」を控える
3. `price-judge` フォルダの `.env.example` をコピーして、名前を **`.env`** に変えます
   - Windows のメモ帳で保存するときは、「ファイルの種類」を **「すべてのファイル (\*.\*)」** にしてから、ファイル名を `.env` と入力してください。そうしないと `.env.txt` になり、キーが読み込まれません（起動時に `.env.txt` を見つけると警告が出ます）
   - エクスプローラーの「表示」→「ファイル名拡張子」にチェックを入れると、名前を確認しやすくなります
4. `.env` をメモ帳で開き、`RAKUTEN_APP_ID=` `RAKUTEN_ACCESS_KEY=` `YAHOO_APP_ID=` の右側に貼り付けて保存
5. もう一度起動すると、黄色い「デモモード」の帯が消え、本物の価格で判定されます
6. 写真から探す機能を使う場合のみ、AIサービスのキーを `LLM_API_KEY=` に設定（費用がかかります。1日の上限は `LLM_DAILY_LIMIT`）

## インターネットに公開する（Render の例）
**キーは Render の画面にだけ入力します。GitHub には入れません。**
1. Mac：`./scripts/package.sh` ／ Windows：`scripts\package.bat` を実行 → `dist/price-judge.zip` ができます（`.env` は入りません）
2. その zip を**別の場所に展開**します（元のフォルダはアップロードに使わない）
3. https://github.com/ で **Private** のリポジトリを作り、展開したフォルダの中身をアップロード
   - アップロード前に、ファイル一覧に `.env` や `data` フォルダが**無いこと**を目で確認してください
   - **Git を使う場合**：このフォルダは Git リポジトリとして初期化済みです（`.gitignore` で `.env`・データベース・`dist`・検品記録を除外）。GitHub で空の Private リポジトリを作り、`git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git` → `git push -u origin main`。push の前に `git status` で `.env` が出ていないことを確認してください
4. https://render.com/ に GitHub アカウントでログイン
5. **プランを決めます**（R3-9）
   - **無料で試す**：推移（価格の履歴）は保存されません（休止・再起動のたびに消えます）。判定は通常どおり動きます
   - **有料（Starter）**：推移を保存するディスク付き。クレジットカード登録が必要です
6. 画面右上の「New +」→「Blueprint」を押し、一覧から手順3のリポジトリの「Connect」を押す
7. 表示された入力画面で：
   - 「Blueprint Name」：分かりやすい名前（例 `price-judge`）
   - 「Branch」：`main` のまま
   - 「Blueprint Path」：**無料なら `render.free.yaml` と入力**／有料なら空欄のまま（`render.yaml` が使われます）
8. 「Apply」または「Deploy Blueprint」の前に表示される入力欄（環境変数）に、楽天・Yahoo のキー、`RAKUTEN_ORIGIN`（公開URL）、関係者限定にするなら `ACCESS_CODE`（12文字以上のランダムな英数字）を入力します
   - `HASH_SALT`・`SESSION_SECRET` は Render が自動で作るので入力不要です
   - `RAKUTEN_ORIGIN` は公開URL（`https://〜.onrender.com`）です。最初は空欄で作成し、URLが決まったら楽天のアプリ設定の「許可するWebサイト」とこの欄の両方に同じURLを入れてください
   - 後から変更するときは、サービスの画面左の「Environment」で編集 →「Save Changes」（自動で再起動されます）
9. 数分後に表示される `https://〜.onrender.com` が公開URLです
10. **公開前に必ず**：`static/terms.html` の［ ］（運営者・連絡先・制定日）を書き換え、README の「公開前チェックリスト」（規約・所属組織のルール）を確認してください。未記入のままだと起動ログに警告が出ます（画面上部の「管理者向けの注意」は、自分のPCで開いたときか、`ADMIN_TOKEN` を設定して `?admin=その値` を付けて開いたときだけ表示されます）

## よくある質問（管理者向け）
- **価格の推移に楽天の価格が出ない**：楽天ウェブサービスの規定（価格情報の保存は24時間まで）に従い、楽天の価格は保存しないためです。判定には楽天の最新価格も使われます
- **職場の誰かがアクセスコードを何度も間違えた**：間違えた端末だけが10分間止まります。同じ回線から合計50回間違えると、その回線から**新しく**入る人も10分間止まりますが、すでに使っている人は止まりません
- **「容量を選んでください」と出る**：iPhone などで容量（128GB 等）によって価格が違う商品は、容量を選ぶとその容量だけで判定します
- **専門店（ケーズデンキ・BEAMS など）の価格が出ない**：専門店の価格は、そのお店の楽天市場店・Yahoo!店から楽天・Yahoo!の公式APIで取得します。APIキーが未設定（デモモード）だと出ません。また商品の種類（家電・服・靴など）が検索語から分からないときは、お店に絞った検索はしません（通常の検索に含まれるお店の出品は店名つきで表示されます）。どのお店で何ができるかは画面下の「対応サイト一覧」で確認できます
- **お店の商品ページのURLを貼ったのに読めない**：そのお店の robots.txt で許可されていないページや、サーバーからのアクセスを拒否しているお店（「対応サイト一覧」で ×）は読みません。商品名で検索してください
