# 価格チェッカー ご提案（概要）

「その値段、高い？安い？」を、信頼できる通販サイトの**実際の価格**と比べて判定する Web ツールです。
服・靴・家電などの購入前に、提示された価格が相場と比べてどうかを、誰でも1画面で確認できます。

---

## 1. 目的
- 通販・店頭で見かけた価格が「安いのか・適正か・高いのか」を、根拠つきで素早く確認できるようにする
- 極端に安い出品（偽物・詐欺・別商品の可能性）に気づけるようにする
- 判定の根拠（どのサイトの、どの出品の、いつの価格か）を必ず示し、利用者が自分で確かめられるようにする

## 2. 使い方と仕組み
1. **入力**：商品名、商品ページのURL、または写真（写真はAIで商品名の候補を出し、利用者が選ぶ）
2. **自動検索**：あらかじめ決めた信頼サイト（許可リスト）から、楽天市場・Yahoo!ショッピングの**公式API**で価格を集める。家電量販店・セレクトショップ・スポーツ店などの専門店は、その店の楽天市場店・Yahoo!店に絞った検索も行い「ケーズデンキ（楽天市場店）」のように店名で表示する
3. **選別**：別モデル・付属品・類似品・中古品・送料不明の出品などを、決まったルールで除外（除外理由はすべて画面に表示）
4. **判定**：残った出品の価格分布の中で、検討中の価格がどの位置にあるかを統計で判定
   - 安すぎ（要注意）／安い／適正／高い／かなり高い
   - 件数や取得元が足りない場合は「**データ不足のため判定不可**」とし、無理に判定しない
5. **ダッシュボード**：判定と理由、中央値・適正価格帯、価格分布、価格の推移、出典一覧（リンク・取得日時つき）

## 3. 信頼性の設計（AIのでっち上げを防ぐ仕組み）
- **価格はAIに作らせない**：画面に出る価格はすべて、信頼サイトから実際に取得した値です。出典のURLと取得日時を必ず表示します
- **判定は計算で行う**：中央値・四分位・外れ値の除外など、毎回同じ結果になる統計処理だけで判定します。AIは判定にも説明文にも関与しません
- **AIの役割は写真からの商品名の候補出しだけ**：最終的な商品は利用者が選びます
- **足りなければ判定しない**：有効な出品が10件未満、取得元が2サイト未満、店舗が3店未満なら判定しません。中古品のように取得元が1サイトしか無い場合は「参考値（判定ではありません）」と明示します
- **紛らわしいものは除外**：別モデル（世代・容量・ハイ/ロー等）、付属品・部品、類似品（「〜風」等）を除外。価格帯が大きく2つに分かれている場合（類似品が多く混ざっている可能性）は判定しません。容量で価格が変わる商品は容量を選んでもらいます
- **デモモード**：APIキーが無いときは、架空のサンプルデータで動作し、画面上部に「架空のサンプルデータ」と常に表示します（本物のデータと混ざることはありません）

## 4. 価格の定義：「総支払額」
- 判定に使うのは **総支払額 ＝ 税込価格 ＋ 送料 ＋ 必須の手数料** です
- 送料・手数料が分からない出品は、**推測せず**判定にも件数にも含めません
- 「実質価格（総支払額 − ポイント）」は、販売サイトがポイントを明示している場合だけ参考表示します（判定には使いません）

## 5. 品質確認の経緯（独立したレビューを3回実施）
作る担当とは別の担当が、毎回「実際に壊してみる」検査（不正な入力・大量の同時利用・紛らわしい商品名など）を行い、指摘をすべて修正しました。

| 回 | 主な指摘 | 対応後の自動テスト |
|---|---|---|
| 第1回 | 過去データで件数が水増しされる、AI説明文の数値の抜け穴（→AI説明文を廃止）、税抜価格の取り違え、判定不可でも価格帯を表示、検索語の保存、クレジット表示、利用制限なし など | 80件 |
| 第2回 | 実際の商品名で照合がほぼ通らない／付属品が通る、公開時にAPIキーが漏れる手順、Render での保存・利用者IP、中古が常に判定不可、アクセスコードの総当たり など | 126件 |
| 第3回 | 楽天の価格を長期保存していた（規約違反のおそれ→保存を廃止）、別名の誤一致（サンバイザー等）、Switch 2・容量違い、類似品が多数のときの誤判定、共有回線でのロックアウト など | **174件（すべて成功）** |

- 第3回の検査結果：**デモモードでの共有は「可」**。本番データでの公開は、下記の準備が済んでからとする判断でした（第3回の指摘はすべて修正済み）
- 照合の検査用データ（実在の店舗風の合成タイトル）では、本物 79件中 78件を正しく通し、付属品・別モデル・類似品など 79件はすべて除外しています

## 6. 対応サイト（専門店を含む36サイト）
- 家電（ヨドバシ・ビックカメラ・エディオン・ケーズデンキ・ジョーシン・ノジマ・ソフマップ・Apple）、服・靴（ZOZOTOWN・BEAMS・UNITED ARROWS・SHIPS・URBAN RESEARCH・atmos・ABC-MART・ユニクロ等）、スポーツ・アウトドア（アルペン・ゼビオ・エルブレス・モンベル・ゴールドウイン）、生活雑貨等（ハンズ・ロフト・ニトリ・マツモトキヨシ・タワーレコード）に対応
- 各店について「公式APIがあるか」「楽天市場・Yahoo!ショッピングに公式店があるか（店舗コードを確認済み）」「商品ページのURLを貼ったときに読めるか（robots.txt と構造化データ）」を調べて記録し、画面の「対応サイト一覧」で誰でも確認できる
- 専門店の自社サイトに価格APIを公開しているところは無く、多くはボット対策でサーバーからの読み取りを拒否している。そのため**規約に沿って使える楽天・Yahoo!の公式APIを経由**して専門店の価格を集める（検索ページの巡回＝スクレイピングはしない）
- Amazon：公式APIは「アソシエイト登録＋直近30日で10件以上の売上」が条件のため未対応。有料の Keepa を契約した場合のみ価格履歴を参考表示

## 7. 本番公開に必要なこと
1. **APIキーの取得**：楽天ウェブサービス（アプリID・アクセスキー）、Yahoo!デベロッパーネットワーク（Client ID）。キーは公開サーバーの設定画面にだけ入力し、ファイルやメールで共有しない
2. **各社の規約確認**
   - 楽天：価格情報の保存は24時間まで → 本ツールは楽天の価格を保存しない設計に変更済み。集計・判定表示の可否は楽天に照会し、記録を残すことを推奨
   - Yahoo!（LINEヤフー）：推移のための長期保存の可否を事前に問い合わせる
   - クレジット表示は各社の規定どおりに設置済み（公開直前に最新の規定と再確認）
   - 専門店の楽天市場店・Yahoo!店の店舗コードが今も正しいか、本物のキーで1回ずつ確認する
3. **利用規約・プライバシーポリシーの運営者情報**：`/terms` の［ ］（運営者・連絡先・制定日）を記入。所属組織の情報セキュリティポリシー（外部クラウド・生成AIへのデータ送信）への適合を確認
4. **実データでの試験**：本物のキーで代表的な約20商品（服・靴・家電）を検索し、判定不可の割合・付属品や別モデルの混入・誤判定の事例を記録する（未実施）
5. **Docker での動作確認**：公開サーバーと同じ方式（Docker）で1回ビルド・起動し、価格推移の保存ができることを確認する（未実施）
6. （関係者限定で試行する場合）アクセスコードを設定し、画面に「試行版・判定は参考」である旨を明記する

## 8. 公開方法・費用の目安
- 自分のPC：配布用 zip を展開し、起動用ファイルをダブルクリック（APIキーが無ければデモモード）
- インターネット公開：Render（クラウド）に配置。無料プランで試行可能（価格推移は保存されない）、推移を保存するなら有料プラン（ディスク付き）
- 写真から探す機能を使う場合のみ、AIサービスの利用料が発生（1日の上限を設定可能）
